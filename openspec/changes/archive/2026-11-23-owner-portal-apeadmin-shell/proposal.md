# Proposal

## Why

货主门户目前只有概览、子账号、入库预报、出库订单四个页面，界面是手写的一套 220px 白底侧栏，与后台 ApeAdmin 的 shell 完全不同；规格承诺的库存查询、账单查询没有实现，"货品档案分工建"里货主该填的"这是什么货"在门户里也没有入口。结果货主登录后能做的事远少于规格描述，页面观感与后台割裂，用户直接反馈"功能过于单一、几乎不可用"。

这次只统一**视觉与交互外壳**，不动"入口分开、登录接口分开、登录即判身份、跨端清会话"这三层隔离。过去分开的是身份链路，不是样式表；共享 shell 组件不会让员工账号进入门户，也不会让货主账号进入后台。

## What Changes

- 货主门户登录后复用后台的 `ApeSidebar` + `ApeHeader` + 主题/i18n/品牌设置体系，菜单继续从 `/auth/userinfo` 的 `/owner` 子树读取，侧栏只显示货主被授权的入口。
- 保留货主门户独立的品牌登录页（`/owner/login`）、独立的 `/owner-login` 接口与身份校验，不改登录视觉。
- 补齐规格已承诺但缺失的门户页面：库存查询、账单查询。
- 新增货主自助创建商品档案的页面与接口：货主只填"这是什么货"的字段（编码、名称、规格、条码、是否启用批次等），仓库侧字段不出现在门户，也不接受门户写入。
- 为上述页面补齐菜单 seed 与角色绑定（主账号可管理、操作员可建单、只读仅查看），并使入口随所属业务域停用而收起。
- 商品列表接口从只读扩展为按会话 `owner_id` 创建，货主不能指定或切换货主，不能操作其他货主的档案。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `wms/owner-access`: 扩展"自助端能力范围"的具体页面集合，明确货主可自助创建商品档案且只提交"这是什么货"字段；明确 shell 视觉与身份隔离解耦——共享 UI 组件不构成跨端访问。
- `wms/stock-ledger`: 新增货主在自助端按本货主查询库存与流水的场景（已有"货主只能看到属于自己的库存"要求，补上自助端入口这一可观察行为）。
- `wms/billing`: 新增货主在自助端查询本货主账单与明细的场景（已有"账单按月结锁定"要求，补上货主可见性）。

## Impact

- 前端：`frontend/src/main-owner.ts`、`OwnerApp.vue`、`layout/OwnerLayout.vue` 改为复用后台 shell；`src/router/owner.ts` 增路由；`src/views/wms_master_data/portal/` 增库存、账单、商品档案页面；`src/api/wms_portal.ts` 增接口调用。
- 后端：`wms_master_data` 插件的 portal API 增商品创建接口、账单查询接口（或复用 `wms/billing` 既有查询并按会话 `owner_id` 过滤）；菜单 seed 与角色绑定补齐。
- 构建：双产物、双入口、base `/owner/` 与 `/admin/`、dev server 入口替换插件保持不变。
- 用户数据：现有 `own001` / `own002` 两个货主主账号的可见菜单会增加，既有账号与密码不变。
