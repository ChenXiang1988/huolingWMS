# Spec Delta

## ADDED Requirements

### Requirement: 货主可通过自助端查询本货主账单

系统 SHALL 让绑定货主身份的账号在自助端查询本货主的账单与明细，账期与范围是唯一查询维度，货主不能通过自助端修改费用或解锁已确认账单。

#### Scenario: 货主查询账单

- **WHEN** 货主账号在自助端打开账单查询页
- **THEN** 展示本货主各账期账单及其费用明细
- **AND** 不返回其他货主的账单

#### Scenario: 已确认账单不可改

- **WHEN** 货主账号在自助端尝试修改费用或确认状态
- **THEN** 请求被拒绝
- **AND** 界面不提供写操作入口

#### Scenario: 账单尚未生成

- **WHEN** 货主查询一个尚无账单的账期
- **THEN** 返回空列表而非错误
- **AND** 不暴露其他货主在同一账期是否有账单
