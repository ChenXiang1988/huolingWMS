# Spec Delta

## ADDED Requirements

### Requirement: 货主可通过自助端查询本货主库存

系统 SHALL 让绑定货主身份的账号在自助端查询本货主的库存数量与流水，查询范围由会话绑定的货主决定，界面不提供货主选择项。

#### Scenario: 货主查询自己库存

- **WHEN** 货主账号在自助端打开库存查询页
- **THEN** 展示该货主名下各商品、批次、库位与状态的可用数量
- **AND** 结果不包含其他货主的数据

#### Scenario: 货主查询流水

- **WHEN** 货主账号在自助端查看库存流水
- **THEN** 每条流水展示来源单据与操作时间
- **AND** 只返回本货主的流水

#### Scenario: 尝试查他人库存

- **WHEN** 货主通过自助端查询接口指定其他货主
- **THEN** 指定被忽略或请求被拒绝
- **AND** 返回结果不泄露其他货主是否存在该商品
