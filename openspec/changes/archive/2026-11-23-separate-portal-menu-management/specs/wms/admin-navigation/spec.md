# Spec Delta

## ADDED Requirements

### Requirement: 菜单管理按端分开维护

系统 SHALL 在后台菜单管理界面把后台菜单与货主门户菜单分成两棵独立的树，管理员在某一端的新增、编辑、删除操作只作用于该端，不跨端修改。

#### Scenario: 分别查看两端的菜单

- **WHEN** 管理员打开菜单管理页
- **THEN** 可在「后台菜单」与「货主门户菜单」两个视图间切换
- **AND** 每个视图只显示属于本端的菜单树

#### Scenario: 在门户视图新增菜单

- **WHEN** 管理员在货主门户菜单视图新增一个菜单
- **THEN** 新菜单落在 `/owner` 子树下
- **AND** 不会出现在后台菜单视图或后台侧栏

#### Scenario: 在后台视图新增菜单

- **WHEN** 管理员在后台菜单视图新增一个菜单
- **THEN** 新菜单不在 `/owner` 子树下
- **AND** 不会被货主账号看到

#### Scenario: 编辑时不能跨端移动

- **WHEN** 管理员尝试把 `/owner` 下的菜单改挂到后台目录，或把后台菜单改挂到 `/owner` 下
- **THEN** 操作被拒绝
- **AND** 两端菜单树保持独立

#### Scenario: 接口层同样隔离

- **WHEN** 调用菜单树或菜单写接口时指定某一端
- **THEN** 返回或写入的菜单只属于该端
- **AND** 未指定端时保持返回全量树，兼容既有调用
