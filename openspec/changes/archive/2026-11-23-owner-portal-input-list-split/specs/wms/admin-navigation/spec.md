# Spec Delta

## ADDED Requirements

### Requirement: 右侧抽屉使用统一外观骨架

系统 SHALL 让管理后台与货主门户的 PC 端右侧抽屉共用统一外观：头部有标题、副标题、状态标签与关闭入口；主体支持左侧分段目录与右侧两列字段；底部操作右对齐。

#### Scenario: 新建抽屉外观

- **WHEN** 用户在任一端的列表页点击「新建」打开右侧抽屉
- **THEN** 抽屉头部显示标题与副标题，主体字段按两段式排列，底部操作靠右
- **AND** 外观与同一端的其他抽屉一致

#### Scenario: 详情抽屉外观

- **WHEN** 用户打开某条记录的详情抽屉
- **THEN** 头部显示记录标识与状态标签
- **AND** 主体按分段目录组织字段，底部为关闭或操作入口

#### Scenario: 两端共用组件

- **WHEN** 后台或门户页面需要使用右侧抽屉
- **THEN** 使用同一个共享抽屉组件而不是各页自写外壳
- **AND** 页面只提供标题、状态、分段内容与底部操作等数据
