## 2. 库存表与记账契约

- [x] 2.1 建 `lot`、`stock`（含 `lot_id` 的四维唯一）、`txn`（含 `lot_id` 与前后状态的幂等键）；验证标准：三条唯一约束在 MySQL 上生效
- [x] 2.2 实现 `post_stock`：锁行顺序 sku→lot→location、先插流水后改数量、唯一键冲突即幂等返回、负库存拒绝；验证标准：同一幂等键调两次只产生一条流水且数量只变一次
      —— 实测：首调 `applied=true` 100；同 `request_id` 再调 `applied=false` 仍 100，流水只两条；扣到 70 后再扣 1000 返回 422
- [x] 2.3 实现 `transfer_status`：一条流水带 `from_status` / `to_status`，总量守恒；验证标准：源状态减、目标状态加，两者之和不变
      —— 实测 available 70 → 转 30 到 frozen 后为 40+30=70，再转回后仍 70
- [x] 2.4 并发过账验证：两个事务同时过账同一库存行；验证标准：不出现双扣，后到的那个等锁后基于最新值计算
      —— `asyncio.gather` 两个会话同时各扣 50（库存 70），结果 `['ok','rejected']`，最终 20
