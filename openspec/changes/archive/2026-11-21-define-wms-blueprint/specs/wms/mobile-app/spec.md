# Spec Delta

## Purpose

仓库作业员要在 Android 手持机上扫码作业。这个能力定的是移动作业端的交付形态边界：一份 Web 构建怎么变成 APK、客户端能不能多拿信任、系统与资源版本怎么卡门槛，以及货主端反过来明确不做移动端。

## ADDED Requirements

### Requirement: 移动作业端复用同一份前端构建

系统 SHALL 让 Android 作业端承载与 Web 端相同的前端代码与后端接口，不为移动端单独实现业务逻辑。

#### Scenario: 功能变更同步生效

- **WHEN** Web 端某个页面或校验规则调整
- **THEN** 作业端在下一次发版后表现一致
- **AND** 不存在需要在两处分别修改的实现

#### Scenario: 接口与鉴权一致

- **WHEN** 作业端调用后端
- **THEN** 使用的是与 Web 端相同的接口与鉴权方式
- **AND** 不因为来自移动端就放宽校验

### Requirement: 作业端只进入移动作业路由组

系统 SHALL 让作业端应用只呈现作业相关界面，不提供货主自助端与后台管理的入口。

#### Scenario: 打开作业端

- **WHEN** 作业员打开应用
- **THEN** 只进入移动作业路由组
- **AND** 无法进入货主自助端或后台管理界面

#### Scenario: 直接访问其他路由组

- **WHEN** 在作业端应用内访问货主端或后台路由
- **THEN** 被拒绝
- **AND** 不因为客户端类型相同而放行

### Requirement: 客户端不获得额外信任

系统 SHALL 以账号权限判定一切，不因请求来自移动作业端而扩大可操作范围。

#### Scenario: 同一账号两端能力一致

- **WHEN** 同一账号分别在 Web 端与作业端操作
- **THEN** 可见数据与可执行动作完全相同

#### Scenario: 伪造客户端标识

- **WHEN** 请求伪造移动端标识
- **THEN** 权限判定结果不变
- **AND** 不出现仅凭客户端标识放行的路径

### Requirement: 系统版本与资源版本都有明确门槛

系统 SHALL 在设备系统版本低于支持范围时给出明确提示，并在应用内资源与服务端接口不兼容时提示升级。

#### Scenario: 系统版本过低

- **WHEN** 设备 Android 版本低于 14
- **THEN** 安装或启动时给出明确提示
- **AND** 不进入一个必然出错的界面

#### Scenario: 应用内资源与服务端不兼容

- **WHEN** 已安装版本的前端资源与服务端接口不再匹配
- **THEN** 启动时提示升级
- **AND** 不静默失败或抛出堆栈

### Requirement: 作业端不做离线作业

系统 SHALL 要求作业端在线操作，断网时明确失败并提示重试，不做本地排队与冲突合并。

#### Scenario: 断网提交

- **WHEN** 无网络时提交作业
- **THEN** 操作失败并给出重试提示
- **AND** 不在本地暂存后自动补传

#### Scenario: 弱网下重复提交

- **WHEN** 网络抖动导致同一操作被提交两次
- **THEN** 由幂等规则收敛为一次
- **AND** 不产生重复任务完成或重复扣减

### Requirement: 货主自助端不提供移动客户端

系统 SHALL 只为作业端提供 Android 应用，货主自助端按桌面浏览器设计，不出安装包。

#### Scenario: 货主提出移动端需求

- **WHEN** 货主要求在手机上使用自助端
- **THEN** 不提供安装包
- **AND** 门户页面不为手机屏幕单独适配

#### Scenario: 验收范围

- **WHEN** 验收货主自助端
- **THEN** 以桌面浏览器的表现为准
- **AND** 窄屏下的可用性不作为验收项
