## 5. 发运

- [x] 5.1 `ship()`：锁订单 → 状态校验 → 每批次一条 `post_stock` 扣减 → 写 `shipment`；验证标准：库存减少量等于订单行数量
      —— 9.1 验收：订单 10 件发运后该库位 52→42
- [x] 5.2 重复发运幂等：状态已 `shipped` 直接返回成功且不再扣减；验证标准：调两次库存只少一次
      —— 9.4 实测第二次返回同一张 `SHP000001`，库存不再变化
- [x] 5.3 分配量与实际库存不符时拒绝发运并提示重分配；验证标准：返回明确原因
      —— 本轮修：`OutboundError` 是 `StockError` 子类，`except OutboundError` 抓不到
      `post_stock` 抛的父类异常，会漏成 500。改为在 `ship()` 内转译成
      「分配量与实际库存不符…请重新分配后再发运」；门禁实测 422 且库存 229→229
