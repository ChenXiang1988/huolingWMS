# Proposal

## Why

蓝图已归档，八份规格成为常驻约束，但仓库里还没有一行代码——`backend/`、`frontend/`、`mobile/` 都不存在。

P0 要做的是把 ApeAdmin 这套基座搬进来、改造成货灵的形态、把主数据与库存两个插件立起来。这件事必须在任何业务代码之前完成，因为后续每个域都依赖它定下的命名前缀、菜单归属规则与建表方式。骨架立错，P1 到 P8 全部返工。

只建两个插件是刻意收窄的：P1 真正用到的只有主数据与库存，其余八个域等对应期次开工时再建，避免一次造出八个空包却无人验证。

同时承接蓝图没定完的九件事，让它们有地方待着，而不是散在对话记录里。

## What Changes

- **搬入基座**：`ApeAdmin-master` 的 `backend/`、`frontend/` 复制为仓库根目录，保留其插件机制、RBAC、菜单与审计，不改 `core/`、`plugins/base.py`、`plugins/manager.py`。
- **改造配置**：应用名、库名、密钥、跨域、MySQL 字符集与排序规则、时区，落进 `.env` 与 `my.cnf`，不硬编码。
- **两个插件包**：`wms_master_data`（建两张账号表 + 一个落点接口 + 域菜单与角色 seed）、`wms_inventory`（纯骨架，声明依赖 `wms_master_data`，不建表）。
- **菜单基线**：清掉基座示例菜单，隐藏插件市场、组件演示、MCP 与 AI 助手菜单，建两个域顶级目录、门户菜单根、四个角色与对应按钮级权限。
- **前端三个布局根**：后台、门户（`/owner`）、作业端（`/m`），登录后按是否绑定货主决定落点。
- **双 Compose 文件**：`docker-compose.yml` 起全栈用于验收与部署，`docker-compose.dev.yml` 只起 MySQL 供宿主热重载开发。

## Capabilities

### New Capabilities

- `wms/platform-bootstrap`: 基座初始化与运行前提——一条命令起环境、配置固化为不可降级、菜单与角色基线、插件骨架可独立启停、登录落点判定

### Modified Capabilities

无。八份既有规格在 P0 不发生变化，P0 只是让系统具备承载它们的骨架。

## 承接自蓝图的未决策

九项待确认，归档的蓝图里它们没有载体了，放在这里跟 P0 一起走。**大部分不阻塞 P0 动工**，各自的最晚时点见括号。

| # | 待确认 | 最晚时点 | 阻塞什么 |
|---|---|---|---|
| 1 | 日单量（B 端）、货主数、SKU 数、库位数、峰值收货批次 | P1 结束 | 选位算法复杂度、报表查询范围 |
| 2 | 货主自助端是否要打面单或入库标签 | P3 前 | 打印代理的目标机型 |
| 3 | PDA 型号与扫码方式（一维/二维码、广播还是键盘模拟、是否带蓝牙打印） | P4 前 | 扫码桥接实现 |
| 4 | 作业端 APK 的分发方式（内部下载页 / 企业分发 / 应用商店） | P5 前 | 是否维护版本清单、审核周期 |
| 5 | 是否强制更新（低于某版本直接不可用） | P5 前 | `/system/version` 的拦截强度 |
| 6 | 面向货主收哪些费项（仓储费按库位数还是体积/重量、操作费按件还是按单、是否收增值服务费） | P6 前 | 费率表结构 |
| 7 | 存储费能否按批次归集 | P6 前 | 与第 6 项联动：按库位日计价归不到批次 |
| 8 | 除货主自有系统外，是否还有电商平台或 ERP 需要主动拉单，各自认证方式 | P7 前 | 推送目标配置形态 |
| 9 | 账期规则（自然月 / 合同起止日，是否预付款抵扣） | P8 前 | 账单状态机 |

已定的不必再议：C 端日单量三万、分播两法并存、波次三种切法、称重拦截、热敏打印走代理、批次按商品开关、破损处置复用逆向域、一个 ASN 多张收货单、库存只存最小单位。这些在归档的 `design.md` 里各有 D 编号。

## Impact

- 新增 `backend/`、`frontend/`、`mobile/`（前两个在 P0 落地，`mobile/` 留到 P5）、`docker-compose.yml`、`docs/`。
- 不改 `openspec/specs/` 下任何常驻规格。
- 引入的运行时依赖全部来自基座，P0 不新增包（`apscheduler`、`qrcode`、`openpyxl` 留到 P4/P6）。
- P0 交付后，P1 可以直接在主数据域里写业务代码，不再需要动骨架。
