# Spec Delta

## MODIFIED Requirements

### Requirement: 自助端只呈现属于该货主的内容

系统 SHALL 让货主账号登录后只见自助端菜单与被授权的功能，且建单能力受货主是否接入上游控制。

#### Scenario: 货主账号的可见范围

- **WHEN** 货主账号登录
- **THEN** 侧边栏只有自助端菜单
- **AND** 直接访问仓库内部路由被拒绝

#### Scenario: 仓库员工不被当成货主

- **WHEN** 未绑定货主的员工登录
- **THEN** 进入后台而非自助端
- **AND** 可查看全部货主数据

#### Scenario: 自助端能力范围

- **WHEN** 货主在自助端操作
- **THEN** 能力限于查库存、查单据进度、查账单、管理子账号
- **AND** 未接入上游的货主还可建单，见下一条
- **AND** 不能操作库位管理、任务执行、盘点等仓库内部功能

#### Scenario: 子账号不见账号管理入口

- **WHEN** 子账号登录
- **THEN** 侧边栏不出现子账号管理入口
- **AND** 直接访问该入口被拒绝

#### Scenario: 已接入上游的货主不建单

- **WHEN** 货主已启用上游同步
- **THEN** 门户与对外接口的建单入口对货主不可见、不可用
- **AND** 订单由上游下发，货主只能查询与跟踪

#### Scenario: 未接入上游的货主照常建单

- **WHEN** 货主未启用上游同步
- **THEN** 门户与对外接口的建单能力保持开放
- **AND** 与已接入上游的货主共用同一套业务规则

#### Scenario: 切换接入开关

- **WHEN** 某货主从未接入改为已接入
- **THEN** 建单入口立即关闭
- **AND** 此前已建的未发货单据仍可继续处理完，不被中断
