# Tasks

P4 交付，与波次同期。

## 1. 前端接入

- [ ] 1.1 装 `vue-plugin-hiprint` 与 `socket.io-client`，在 `index.html` 引入 `print-lock.css`；验证标准：设计器页面能打开并拖出元素
- [ ] 1.2 封装打印服务：按模板类型取模板、绑定数据、选择目标客户端下发；验证标准：传入一份模板与数据能打出纸
- [ ] 1.3 监听客户端连接状态，离线时页面顶部常驻提示；验证标准：关掉客户端后 3 秒内出现提示
- [ ] 1.4 打印结果回写后端；验证标准：成功与失败两条记录都能在打印记录里查到

## 2. 模板管理

- [ ] 2.1 建 `wms_print_template` 表与后台管理页，支持新建、编辑、试渲染、启停；验证标准：保存一份面单模板后立即可被打印服务取到
- [ ] 2.2 同一类型只允许一个启用模板，切换时旧的自动停用；验证标准：启用新版后旧版停用，打印取到新版
- [ ] 2.3 保存前试渲染一次，失败拒绝保存；验证标准：故意存一份坏 JSON，被拦住并给出原因
- [ ] 2.4 首批模板：面单、库位标签、商品标签、托盘标签、包裹标签、拣货单、装箱单；验证标准：七种都能打出可扫的结果

## 3. 业务串联

- [ ] 3.1 复核通过后自动触发面单打印；验证标准：一次复核出且只出一张面单
- [ ] 3.2 重打时旧任务作废、新任务生效，面单号不变；验证标准：打印记录里只有一条有效记录
- [ ] 3.3 电子面单 PDF 转图片后整幅贴入模板；验证标准：打出的面单与快递平台预览一致，条码可扫
- [ ] 3.4 库位标签在库位建档后可批量打印；验证标准：一次选 20 个库位打出 20 张

## 4. 验收

- [ ] 4.1 真机连续打 500 张面单并计时；验证标准：得出单张耗时，据此确定打包工位与客户端数量
- [ ] 4.2 打出的二维码用 PDA 在 30 cm 外扫；验证标准：连续 50 张全部一次扫中，否则回退 ZPL 方案
- [ ] 4.3 拔掉打印机数据线后打印；验证标准：页面提示失败原因，任务记录为 failed，可换机重打
- [ ] 4.4 关闭客户端后打印；验证标准：不静默失败，不产生"已打印"记录
