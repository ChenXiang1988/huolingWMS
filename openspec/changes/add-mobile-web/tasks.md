# Tasks

P5 交付，P0–P4 不涉及。

## 1. 浏览器形态

- [ ] 1.1 把 `frontend/dist` 挂进 nginx，使 `/m/*` 可被浏览器直接访问；验证标准：不装 APK，浏览器打开作业端地址能进任务列表
- [ ] 1.2 移动作业布局在桌面浏览器下按窄屏容器居中，不做全宽拉伸；验证标准：1920 宽屏与 390 手机屏上排版都不散
- [ ] 1.3 加浏览器版本门槛：Chrome 110 / Safari 16.4 以下挡住并提示；验证标准：用 UA 覆盖工具模拟低版本，页面给出明确提示而非白屏
- [ ] 1.4 版本判定加功能探测兜底；验证标准：伪装 UA 的浏览器若缺关键 API，同样被挡住

## 2. 扫码与打印

- [ ] 2.1 扫码输入统一走「广播优先、键盘模拟兜底」；验证标准：同一设备禁用广播后仍能扫码录入
- [ ] 2.2 处理焦点丢失：扫码后焦点回到当前输入框；验证标准：连续扫 20 次不丢字符
- [ ] 2.3 浏览器形态调用打印代理出 100×150 面单；验证标准：与 APK 形态打出的面单一致

## 3. 验收

- [ ] 3.1 用浏览器完成一次完整作业：领任务 → 扫码 → 提交 → 打面单；验证标准：库存与单据状态正确，与 APK 形态结果一致
- [ ] 3.2 对比两种形态的可见菜单与可执行动作；验证标准：完全一致，无"浏览器少了某个按钮"
- [ ] 3.3 token 过期后任一操作跳登录；验证标准：不出现"点了没反应"
