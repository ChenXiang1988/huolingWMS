# Tasks

P5 交付，P0–P4 不涉及。

## 1. 浏览器形态

- [x] 1.1 把 `frontend/dist` 挂进 nginx，使 `/m/*` 可被浏览器直接访问；验证标准：不装 APK，浏览器打开作业端地址能进任务列表
      —— 容器内 `docker compose up -d --build` 后 `http://host:8080/m/tasks` 返回 200 并加载 `/admin/index.html`，
      nginx 的 `location /` 回退到此。注入 token 后页面渲染出任务列表（待领取/进行中、
      上架 TSK000063、拣货 TSK000061 等）。注意 vue-router 的 base 是 `/admin/`，
      站内跳转会把地址补成 `/admin/m/tasks`，两条路径都能打开
- [x] 1.2 移动作业布局在桌面浏览器下按窄屏容器居中，不做全宽拉伸；验证标准：1920 宽屏与 390 手机屏上排版都不散
      —— 实测 1920×900：容器宽 430、左右各留 745，正中；390×844：容器宽 390、占满无留白。
      布局本来就是 `max-width: 430px` + flex 居中，本次只把头部的「P0 占位」换掉
- [x] 1.3 加浏览器版本门槛：Chrome 110 / Safari 16.4 以下挡住并提示；验证标准：用 UA 覆盖工具模拟低版本，页面给出明确提示而非白屏
      —— `composables/useBrowserGate.ts`，门槛卡在 `MobileLayout` 里（门口提示本身也得能渲染，
      放路由守卫反而会白屏）。模拟 Chrome 96 的 UA 后整页只剩提示：
      「检测到 Chrome 96，作业端需要 Chrome 110 及以上」
- [x] 1.4 版本判定加功能探测兜底；验证标准：伪装 UA 的浏览器若缺关键 API，同样被挡住
      —— 功能探测先于版本判定，检查 `crypto.randomUUID`、`structuredClone`、`ResizeObserver`。
      实测：UA 保持正常、删掉 `structuredClone`，页面提示「缺少作业端依赖的能力：structuredClone」。
      这样伪装 UA 的国产内核绕不过去

## 2. 扫码与打印

- [x] 2.1 扫码输入统一走「广播优先、键盘模拟兜底」；验证标准：同一设备禁用广播后仍能扫码录入
      —— `composables/useScanGun.ts`：`window.__scanBroadcast` 存在则走广播（APK 原生层注入），
      否则监听 `keydown`，按 60ms 字符间隔区分扫码枪与人工输入，`MIN_LENGTH=3` 防误触。
      实测：把焦点移到 body（等价于「没有广播、也没有输入框接管」）后敲 `FOCUS-LOST-0001`，
      全局监听捕获、查询触发、焦点回到扫码框。页面底部显示当前通道，浏览器形态为「键盘模拟」
- [x] 2.2 处理焦点丢失：扫码后焦点回到当前输入框；验证标准：连续扫 20 次不丢字符
      —— 实测 20 次连续扫码（`SCAN-TEST-0001` 到 `0020`，字符间隔 12ms）：
      20 次录入完整、20 次焦点回到 `#mobile-scan`、输入框无残留字符
- [ ] 2.3 浏览器形态调用打印代理出 100×150 面单；验证标准：与 APK 形态打出的面单一致
      —— 阻塞：打印代理与模板尚未实现（`adopt-hiprint-print` 0/16，`print_template` 页是说明页）
