# Spec Delta

## Purpose

让车辆到货、月台分配与签到在系统里留痕，为按工序组织的仓库提供入库前置环节。签到是独立单据，与 ASN 弱关联、不嵌入 ASN 状态机，使现有"到货系统无感知"的入库主链路保持不变。

## ADDED Requirements

### Requirement: 签到单据独立于 ASN 并弱关联
系统 SHALL 让每张签到单据独立存在，通过引用字段指向 ASN 或仓库自建工单，不修改被引用单据的状态与结构。

#### Scenario: 为已知 ASN 建签到单
- **WHEN** 仓管为一 arriving 的 ASN 建签到单据
- **THEN** 签到单据记录 ASN 的 id 与 code 作为引用
- **AND** ASN 的状态不因签到单据的建立或签到而改变

#### Scenario: 无 ASN 直接建签到单
- **WHEN** 一辆车到货但尚无 ASN
- **THEN** 可直接建签到单据，记录车辆与承运商信息
- **AND** 不强制先建 ASN 才能签到

#### Scenario: 关联仓库自建工单
- **WHEN** 签到单据由工单的到货签到工序触发
- **THEN** 签到单据记录来源工单与工序标识
- **AND** 工单不直接改写签到单据的业务字段

#### Scenario: 签到单据可独立查询
- **WHEN** 查询一张签到单据
- **THEN** 能看到车辆、承运商、司机、预约时段、实际到场时间、月台与签到状态
- **AND** 能通过引用字段跳转到 ASN

### Requirement: 签到记录车辆到场与月台分配
系统 SHALL 记录车辆实际到场时间、分配的月台与签到人，并把未签到与已签到状态区分开。

#### Scenario: 车辆到场登记
- **WHEN** 车辆到达并登记
- **THEN** 记录实际到场时间与车辆标识，状态为待签到
- **AND** 不因为没有 ASN 而拒绝登记

#### Scenario: 月台分配
- **WHEN** 仓管为已登记的车辆分配月台
- **THEN** 签到单据记录月台编号与分配时间
- **AND** 同一时段同一月台不分配给两辆车

#### Scenario: 司机扫码签到
- **WHEN** 司机或仓管在月台扫码完成签到
- **THEN** 签到单据状态转为已签到，记录签到人与签到时间
- **AND** 触发验货工序进入可执行状态

#### Scenario: 未签到不可验货
- **WHEN** 对一张未签到的单据尝试开始验货
- **THEN** 请求被拒绝并提示先完成签到
- **AND** 不产生收货单与库存变动

#### Scenario: 重复签到被拒绝
- **WHEN** 对已签到的单据再次签到
- **THEN** 请求被拒绝或幂等返回原签到结果
- **AND** 不覆盖首次签到时间

### Requirement: 签到任务可拆派到多个 PDA
系统 SHALL 把需要多人协同的到货签到拆成多条任务派到不同 PDA，货量小时可单人完成。

#### Scenario: 单人完成签到
- **WHEN** 一次到货量在单人处理范围内
- **THEN** 生成一条签到任务由一人完成
- **AND** 不强制拆分

#### Scenario: 按车辆或批次拆签到任务
- **WHEN** 到货含多辆车或多个批次且货量超过单人处理上限
- **THEN** 按车辆或批次拆成多条签到任务
- **AND** 每条任务可派给不同 PDA 与登录人

#### Scenario: 签到任务派工
- **WHEN** 签到任务生成后
- **THEN** 按派工规则指派到作业员或 PDA
- **AND** 同一任务只落一个执行人

#### Scenario: 签到任务完成汇总
- **WHEN** 全部签到任务完成
- **THEN** 签到单据转为已签到
- **AND** 各任务覆盖的车辆或批次之和等于签到单据总量

#### Scenario: 部分任务完成
- **WHEN** 存在未完成的签到任务
- **THEN** 签到单据保持待签到并标出未完成部分
- **AND** 不触发验货工序解锁

### Requirement: 滞留时长与签到记录可追溯
系统 SHALL 统计从到达到签到的滞留时长，并保留签到全过程记录。

#### Scenario: 滞留时长统计
- **WHEN** 查看一张签到单据
- **THEN** 能算出实际到场时间到签到时间的滞留时长
- **AND** 未签到时显示当前已滞留时长

#### Scenario: 签到流水可追溯
- **WHEN** 查看签到记录
- **THEN** 能看到登记时间、月台分配时间、签到时间、签到人、分配与改派历史
- **AND** 能定位到对应的签到任务

#### Scenario: 单据归属唯一货主
- **WHEN** 仓管创建签到单据
- **THEN** 单据绑定唯一货主，全部签到任务与明细同属该货主
- **AND** 无法签到后再补入其他货主的车辆

#### Scenario: 按货主过滤查询
- **WHEN** 货主方用户查询签到单据
- **THEN** 只返回本货主的记录
- **AND** 总数与分页按该范围计算
